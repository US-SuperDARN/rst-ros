Radar Control Program Name:
==========================
rocketsound

Control Program ID (CPID):
=========================
1111

Parameters:
==========
nbeams: 18
intt: 3.2 s
scan: 1 min
ngates: 75+
frang: 180 km
rsep: 45 km

Description:
===========
rocketsound is a variant on the normalsound radar control
program that scans through 3 frequencies on 3 selected beams
twice per minute, and is intended to run on Channel B
simultaneously with pcodescan on Channel A. This control
program was originally designed for the Nov 2026 SYSTER
rocket launch in coordination with the Hankasalmi radar.
